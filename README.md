# Hi, I'm Alan Gomez 👋

**Software Engineer at [supe.ai](https://supe.ai)** · Backend & full-stack · Based in Kochi, Kerala 🇮🇳

I build production web systems where correctness matters: payments, inventory, bookings and auth. I care about clean layered architecture, transactional safety, and code that holds up under race conditions and retries.

- 💼 Freelance work for international clients (headless commerce, booking systems)
- 📚 Pursuing a BCA at IGNOU, and learning **Docker** and **Kubernetes**
